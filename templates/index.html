How it works

  1. 1. You set the ceiling. Budget, preferences and any images you choose to share.
  2. 2. We prompt Gemini for structure. Role, hard constraints and a strict JSON schema - never free-form prose.
  3. 3. We reconcile the numbers. Every category is forced to sum to your exact budget before it renders.
  4. 4. We build real links. Server-side platform registry, so the model can never hallucinate a URL.
